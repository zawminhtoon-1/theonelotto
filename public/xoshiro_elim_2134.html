Combinatorial set-difference: (Modular Cycle native K=38 ∩ xoshiro K=38) pick, minus combos covered by any of the 16 prediction methods' K=19 picks, minus a handful of well-supported pattern filters

Base (below) is Modular Cycle's NATIVE K=38 pick — the direct top-38 numbers by mod-43-residue frequency rank, with no cross-method-consensus padding — intersected with xoshiro256** K=38 seed #692,809's pick, both for draw #2134, walk-forward trained on all real draws through #2133 (the latest real/confirmed draw). This is a different construction from the #2133 elimination page, which used Modular Cycle's cross-method-padded K=33 pick; see the native-K38×K38 stats page for the full walk-forward backtest of this construction. It defines the working universe: all C(34,6) = 1,344,904 six-number combinations drawable from this 34-number pool.

Why this construction, for this draw specifically: for #2133 (the draw just before this one), this exact native-K38×K38 Base fully contained the real winning combo — all 6 main numbers and the bonus — while the K33-padded Base used on the #2133 elimination page missed it (it was short one number). That's one data point, not a validated edge: the stats page's full walk-forward backtest across #44–2132 finds this construction is not statistically significant in aggregate on any tier (hit6b/hit6/hit5/hit4 all p>0.05 vs. the hypergeometric chance baseline). It's used here because it happens to be the most promising Base construction on the site right now, not because it's been proven to work.

Pass 1 is each of the 16 prediction methods' K=19 pick for draw #2134, computed walk-forward (trained on all 2,133 real draws through #2133) then normalized to exactly 19 numbers via the same cross-method-consensus trim/pad algorithm as backtest.html's topKNums(). Any of Base's combos fully contained within ANY single one of these 16 sets gets removed, leaving 1,251,571.

Pass 2 is xoshiro256** K=21 seeds 0, 1, 2 — the same K=21 algorithm used on the 0–1,000 seed page. Each seed's K=21 pick for draw #2134 uses the same verified xoshiro256** implementation as Base's xoshiro side. Any Pass-1-remaining combo fully contained within ANY single one of these 3 picks gets removed, leaving 1,223,031.

Pass 3 is a historical repeat filter — the same "zero repeats in history" pattern used throughout this site's elimination pages. Any Pass-2-remaining combo that exactly matches an actual 6-number winning combo from any of the 2,133 real draws (#1–2133) gets removed, leaving 1,222,621. No K=6 Loto 6 combo has ever repeated across 2,133 draws, so this pass strictly removes exact historical matches, not near-misses.

Pass 4 is the Worst Combo (Anti-Pick) K=15 pick for draw #2134 — the MA-43 + Exp-weighted + Random Forest + kNN + Apriori Association Rules consensus, same 5-method combination as the Predictions page's Worst Combo panel. Any Pass-3-remaining combo fully contained within this 15-number pick gets removed. These 5 methods can't all run client-side, so the pick is computed directly here (from the same 5 methods' native picks above, indices into Pass 1's 16-method table, using the same union-count-desc-then-ascending-number combining rule as the Predictions page's own consensus logic) and embedded as static data, same convention as Modular Cycle's pick.

Pass 5 removes any Pass-4-remaining combo containing a run of 3 or more consecutive numbers — based on the historical finding that only 6.62% of all real Loto6 draws through #2133 have such a run (a run of 5 or 6 has never happened), so this pass removes combos matching that same rare pattern. Any Pass-4-remaining combo with max consecutive run ≥3 gets removed, leaving 1,147,888.

Pass 6 removes any Pass-5-remaining combo that decomposes into exactly three consecutive pairs — each a run of exactly 2, no run of 3+, no isolated singles (e.g. 1,2,9,10,15,16) — a pattern matched by only a small handful of real Loto6 draws to date. Any Pass-5-remaining combo matching it gets removed, leaving 1,146,300.

Pass 7 (final) removes any Pass-6-remaining combo that shares 5 or 6 numbers with the immediately previous actual draw ("1 step back") — #2133: 1, 11, 14, 20, 29, 38. Unlike the "3, 4, or 5 overlap" heuristics used on earlier elimination pages (which this page deliberately drops — see below), this narrower 5-or-6 criterion has a clean historical basis: across all 2,132 consecutive real-draw pairs on this site (#1–2133), an overlap of 5 or 6 numbers between adjacent draws has never once occurred (0/2,132). Leaves 1,146,291.

Why passes 7–10 from earlier elimination pages (e.g. #2133) are dropped here: those pages removed any combo overlapping 3, 4, or 5 numbers with a recent draw, at increasing scope (1/2/3 steps back, then the last 100 draws at once). This site's own significance testing found that heuristic doesn't hold up — the 1-step-back version's binomial test came back p=0.071 (missing the conventional 5% threshold, with the 4-overlap tier actually running above chance), and a pooled ~100,000-comparison check behind the broadest version landed within a few hundredths of a percent of the exact chance rate at every tier. The 5-or-6-overlap case is different in kind, not just degree: it isn't a "somewhat rarer than chance" claim needing a significance test to distinguish from noise, it's a hard zero across the entire dataset — the strongest empirical basis of any filter used on this site. This page keeps only that one, well-supported case.

Pass 3's historical combo set is embedded and checked client-side too.
