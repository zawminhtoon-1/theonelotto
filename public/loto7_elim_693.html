✂️ Loto 7 — Draw #693 Elimination

Combinatorial set-difference: ARIMA's K=25 Base pool, minus combos covered by any of the 16 prediction methods, minus statistically-validated pattern filters

Base construction — tested, not assumed. Before building this page, we walk-forward backtested whether intersecting Base with the completed xoshiro K=25/28/30 Loto7 seed scans' best seeds would strengthen it (same rigor as the Loto6 seed-intersection pages), across all 692 real Loto7 draws:

ARIMA K=25 alone
containment (actual draw fully inside pool): 4.35% (30/690)
~chance level for a random 25-of-37 pool (4.67%)
ARIMA ∩ 1 xoshiro seed
pool shrinks to ~17–20 numbers
containment: 0.29%–1.45% — worse
ARIMA ∩ all 3 xoshiro seeds
pool shrinks to ~10 numbers
containment: 0% (0/690) — never once contained the real combo

Intersecting Base with any xoshiro seed makes it worse, not better — the pool shrinks enough that it stops reliably containing the actual winning numbers at all. Decision: Base stays ARIMA(2,1,0) K=25 alone, not intersected with any seed scan. (Also worth noting: even ARIMA alone barely beats the chance level for containment — this Base isn't a strong signal on its own, it's a starting point the elimination passes then narrow down.)

Base is ARIMA(2,1,0)'s K=25 pick for draw #693 (not yet drawn) — read from the live /loto7/predictions page's data (ARIMA's native K=15 pool, normalized to K=25 via topKNums(), the same generic cross-method-consensus trim/pad function used throughout this site). It defines the working universe: all C(25,7) = 480,700 seven-number combinations drawable from this 25-number pool.

Pass 1 is each of the 16 prediction methods' K=22 pick for draw #693 (native K=15 pool normalized to K=22), checked independently — NOT a union of raw numbers. Any Base combo fully contained within ANY single one of these 16 K=22 sets gets removed, leaving 149,932.

Pass 2 is 4 specific methods' K=25 pick for draw #693 — MA-37, Poly deg-2, Hidden Markov Model, Weighted MA-37 — checked independently. Any Pass-1-remaining combo fully contained within ANY single one of these 4 K=25 sets gets removed, leaving 86,623.

Pass 3 is a historical repeat filter — the same "zero repeats in history" pattern used on the Loto6 elimination pages. Any Pass-2-remaining combo that exactly matches one of Loto7's 692 historical actual winning combos (draws #1–692, main 7 numbers only, bonus ignored) gets removed, leaving 86,620.

Pass 4 (NEW) is the Worst Combo (Anti-Pick) K=15 pick — MA-37, Exp-weighted, Random Forest, kNN (k=10), Apriori Assoc Rules consensus, the exact Loto7 analog of the 5-method combination used on the Loto6 pages' Worst Combo panel. Any Pass-3-remaining combo fully contained within this 15-number pick gets removed, leaving 86,620.

Pass 5 (NEW) removes any Pass-4-remaining combo containing a run of 4+ consecutive numbers. Validated first, same rigor as the Loto6 pages: across all 692 real Loto7 draws, run≥3 occurs in 15.32% of draws — too common to be a meaningful pattern, so it was rejected (unlike Loto6, where 6.62% was judged rare enough to use). run≥4 occurs in only 18/692 draws (2.6%) — comparably rare to Loto6's threshold, so this is the one actually used. Leaves 84,380.

Pass 6 (NEW) removes any Pass-5-remaining combo that decomposes into exactly three consecutive pairs plus one leftover single number (e.g. 1,2,9,10,15,16,23) — the natural Loto7 analog of Loto6's "three consecutive pairs" pattern (Loto6's exact-6-numbers-as-3-pairs pattern doesn't map onto Loto7's 7 numbers, so this adds the necessary 7th "single" slot). Validated first: occurs in only 4/692 real draws (0.58%) — comparably rare to Loto6's pattern. Leaves 82,711.

Pass 7 (NEW, final) removes any Pass-6-remaining combo that shares 5 or more numbers with the immediately previous actual draw ("1 step back") — #692: 7, 9, 15, 18, 20, 28, 31. Validated first via hypergeometric expectation (pool=37, 7-of-37 draws) against all 691 consecutive real-draw pairs — explicitly checking the weak heuristic this site rejected for Loto6: overlap=3 occurred in 70/691 pairs (10.13%), essentially matching the 9.32% chance expectation — rejected, same conclusion as Loto6's abandoned 3-overlap idea. overlap=4 (1.59% observed vs 1.38% expected) was also rejected as too close to chance. overlap≥5 has never once occurred (0/691, vs a near-zero 0.09% chance expectation) — well-supported, adopted. Leaves 82,705.

Passes 3, 5, 6 and 7 are recomputed live in your browser below (pure JS, pattern/historical checks, no PRNG involved in this page) and checked against server-embedded references — check the verification badges. Passes 1, 2 and 4's 16-method ML ensemble can't (practically) run in a browser, so those are precomputed server-side and embedded as static data.
